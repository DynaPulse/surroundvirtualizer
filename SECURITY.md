# Security Policy

## Supported Versions

The following table lists the versions of the Surround Virtualizer project that are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

> Only the latest stable version (1.0.x) is supported. Older versions are not maintained.

## Reporting a Vulnerability

If you discover a security vulnerability in Surround Virtualizer:

1. **Contact**: Email [DynaPulse@users.noreply.github.com] or open a private security advisory on GitHub.
2. **Response Time**: You will receive a confirmation within 48 hours. Updates and a timeline for a fix will be provided within 7 days.
3. **Disclosure**: Please do not publicly disclose the vulnerability until a fix is released.
4. **Resolution**: Once resolved, a patch will be released and you will be notified.

## Security Best Practices
- Only use trusted HRTF files and libraries.
- Do not run the application with elevated privileges.
- Keep dependencies up to date.
- Report any suspicious behavior or potential vulnerabilities promptly.

Thank you for helping keep Surround Virtualizer secure!
